# vim 入門ガイド(Cの学習で使うレベル)

## 0. vim って何?

**vim = ターミナル内で動くエディタ**

VS Code みたいな GUI エディタの「ターミナル版」。
- マウス使わない、キーボードだけで操作
- 軽い、どこでも動く(SSH先のサーバでも使える)
- 慣れると爆速

**最初は絶対詰まる。**でも慣れると武器になる。
本格的に使いこなすには時間かかるが、**Cの学習で使う最低限**だけならすぐ覚えられる。

---

## 1. vim の最大の特徴: モード切替

普通のエディタと根本的に違う点。
**vim には「モード」がある**。

| モード | 何をする | 入り方 |
|---|---|---|
| ノーマルモード | 移動・コピー・削除など操作 | 起動時はこれ |
| インサートモード | 文字を入力する | `i` を押す |
| コマンドモード | 保存・終了・検索など | `:` を押す |

**重要なルール:**
- 文字を打ちたい → インサートモード(`i`)
- 操作したい → ノーマルモード(`Esc`)
- 保存・終了したい → コマンドモード(`:`)

---

## 2. 最低限のフロー(これだけで生きていける)

### ファイルを開く・新規作成

```bash
vim hello.c
```

ファイルがなければ新規作成、あれば開く。

### 文字を入力する

vim を起動したら **ノーマルモード**。このままじゃ文字打てない。

1. **`i` を押す** → 画面下に `-- INSERT --` と出る
2. これで文字が打てる

### 入力をやめる

- **`Esc` を押す** → ノーマルモードに戻る

### 保存して終了

ノーマルモードで:

1. **`:` を押す**(画面下に `:` が出る)
2. **`wq` と打って Enter**

`:wq` = write(保存) + quit(終了)

### 保存せず終了したい

ノーマルモードで:
- **`:q!` + Enter** = 強制終了(変更破棄)

### よく使う組み合わせ

| やりたいこと | 押すキー |
|---|---|
| 編集モードに入る | `i` |
| 編集モードから抜ける | `Esc` |
| 保存だけ | `:w` + Enter |
| 保存して終了 | `:wq` + Enter |
| 保存せず終了 | `:q!` + Enter |
| ヘルプを見る | `:help` + Enter(`:q` で抜ける) |

---

## 3. 詰まった時の脱出法

vim 初心者が絶対ハマる罠。

### 「キー押しても文字打てない」
→ **ノーマルモードにいる**。`i` を押してインサートモードに入る。

### 「`:wq` 打ったのに変なことになった」
→ ノーマルモードで打ってない。**まず `Esc` を1〜2回押してから** `:wq`

### 「もう諦めて閉じたい」
→ `Esc` 連打 → `:q!` Enter で強制終了

### 「画面の表示が変、スクロールしちゃう」
→ 何か変なキー押した可能性。`Esc` 連打して落ち着く。

### 「Ctrl+S 押したらフリーズした」
→ vim では Ctrl+S は画面ロック。**Ctrl+Q で解除**できる。Ctrl+S は使わない。

## 4. ノーマルモードの便利な操作(慣れてきたら)

最初は `i`(編集) と `:wq`(保存終了) だけでいい。
慣れてきたらこの辺を覚えると爆速になる。

### カーソル移動(ノーマルモード)

| キー | 動き |
|---|---|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |

矢印キーでもOK。`hjkl` は慣れるとホームポジションから手を離さなくて済むので速い。

### ジャンプ系(ノーマルモード)

| キー | 動き |
|---|---|
| `gg` | ファイルの先頭へ |
| `G` | ファイルの末尾へ |
| `0` | 行の先頭へ |
| `$` | 行の末尾へ |
| `5G` | 5行目へジャンプ |

### 編集系(ノーマルモード)

| キー | 動き |
|---|---|
| `i` | カーソル位置で編集モード |
| `a` | カーソルの**右**で編集モード(append) |
| `o` | 次の行を作って編集モード |
| `O` | 前の行を作って編集モード |
| `x` | 1文字削除 |
| `dd` | 1行削除 |
| `yy` | 1行コピー |
| `p` | ペースト |
| `u` | アンドゥ(やり直し) |
| `Ctrl+r` | リドゥ |

### 検索(ノーマルモード)

| キー | 動き |
|---|---|
| `/検索文字 + Enter` | 下方向検索 |
| `?検索文字 + Enter` | 上方向検索 |
| `n` | 次の検索結果 |
| `N` | 前の検索結果 |

### 置換(コマンドモード)

```
:%s/old/new/g
```

ファイル全体で `old` を `new` に置換。

## 5. C言語学習に便利な設定

`~/.vimrc` を作ると vim の動作をカスタムできる。

```bash
vim ~/.vimrc
```

中身:

```vim
" 基本設定
set number              " 行番号表示
set tabstop=4           " タブ幅4
set shiftwidth=4        " インデント幅4
set expandtab           " タブをスペースに変換
set autoindent          " 自動インデント
set smartindent         " 賢いインデント
syntax on               " シンタックスハイライト
set hlsearch            " 検索結果ハイライト
set incsearch           " インクリメンタル検索

" C言語向け
set cindent             " C言語スタイルのインデント
```

これで vim が一気に使いやすくなる。

## 6. Cファイル編集の実例

```bash
vim hello.c
```

1. vim 起動 → ノーマルモード
2. `i` 押す → インサートモード(画面下 `-- INSERT --`)
3. コード書く:
   ```c
   #include <stdio.h>

   int main(void) {
       printf("Hello, World!\n");
       return 0;
   }
   ```
4. `Esc` 押す → ノーマルモードに戻る
5. `:wq` 押して Enter → 保存して終了
6. ターミナルで:
   ```bash
   gcc hello.c -o hello
   ./hello
   ```

これだけで Hello World が動く。

## 7. vim を使う気がしないなら

正直、vim は最初の習得コストが高い。
他に使える選択肢:

### `nano`(超簡単、初心者向け)

```bash
nano hello.c
```

- モードなし、起動した瞬間から文字打てる
- 画面下に操作キー一覧が出てる
- 保存: `Ctrl+O` → Enter
- 終了: `Ctrl+X`

### VS Code(GUIエディタ)

WSL や Linux デスクトップでは VS Code を入れる人が多い:

```bash
sudo snap install code --classic
```

`code hello.c` で開ける。普通の GUI エディタ。

### おすすめ

- **学習段階で**: `nano` でいい。詰まる時間がもったいない
- **慣れてきたら**: vim を覚える(SSH先のサーバで必須スキルになる)
- **本格開発**: VS Code(補完・デバッグ・git連携が強い)

vim は「やる気がある時に少しずつ慣れる」スタンスで十分。
**Cの学習を vim 学習で止めるな**、これが一番大事。

## 8. まとめ(これだけ覚えればOK)

| シチュエーション | キー操作 |
|---|---|
| ファイルを開く | `vim ファイル名` |
| 文字を入力する | `i` を押してから打つ |
| 入力をやめる | `Esc` |
| 保存して終了 | `Esc` → `:wq` → Enter |
| 保存せず終了 | `Esc` → `:q!` → Enter |
| 詰まった | `Esc` 連打 → `:q!` で強制終了 |

これだけで C 学習中の vim 操作は全部こなせる。
他のキーは必要になったら都度覚える、で十分。
